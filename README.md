# Alejandro García Asensio · Página personal

Página de presentación y currículum en español, realizada con HTML, CSS y JavaScript sin compilación ni dependencias de ejecución. Diseño adaptable a móvil y ordenador, navegación accesible, filtros de ponencias, descarga del CV y enlaces de contacto.

## Vista previa

Desde esta carpeta: `python3 -m http.server 8080`. Abrir `http://localhost:8080`.

## Publicación

Compatible con cualquier alojamiento estático. En GitHub Pages, seleccionar la rama `main` y la carpeta raíz en Settings → Pages → Deploy from a branch. No requiere configurar variables ni instalar paquetes.

## Edición

- `index.html`: perfil, experiencia, proyectos, formación y contacto.
- `styles.css`: diseño y adaptación a pantallas pequeñas.
- `app.js`: listado de ponencias, filtros y menú móvil.
- `assets/`: fotografía optimizada, currículum original y favicon.

Contenido basado en el currículum facilitado en octubre de 2026. La ponencia de noviembre de 2026 se presenta como próxima. La representación del libro es una composición tipográfica ilustrativa, no su cubierta oficial. Google Fonts carga Manrope y DM Sans; se usan fuentes del sistema si no hay conexión. No se incluyen analítica ni formularios que almacenen datos.
